# Website Project for my personal website

This website is intended to give a short overview about me, my life, my thoughts, camera pictures and much more. 

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## creators and contributors

I created the whole design myself, using figma and also started with the basic implementation myself. **Claude** was mostly used, during the process of creating basic texts and possible previews. Most of these previews helped radically improving text, enhancing the design and sped up the whole development process. 

At publishing time of the website (12.11.2026) most of the texts are still done by claude. However I intend to start working my own way trough editing the site contents and use claude only for idea creation, seo optimization and better readability. 


## How to run the dev server

Run the following command in your shell and open [http://localhost:3000](http://localhost:3000) with your browser.

```bash
npm run dev
```
